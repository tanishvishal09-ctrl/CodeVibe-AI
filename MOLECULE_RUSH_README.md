# Molecule Rush 2.0 - Game Documentation

## Overview
Molecule Rush 2.0 is an educational chemistry game designed to help students learn about molecules, chemical formulas, and their properties in an engaging and interactive way.

## How to Play

### Opening the Game
Simply open `molecule-rush.html` in any modern web browser (Chrome, Firefox, Safari, Edge).

### Game Mechanics

#### Objective
Match molecules with their correct properties to score points and advance through levels!

#### Gameplay
1. A molecule name and its chemical formula will be displayed
2. Read the question carefully
3. Choose the correct answer from the multiple choice options
4. Earn points for correct answers
5. Lose a life for wrong answers
6. Progress through increasing difficulty levels

#### Scoring System
- **Correct Answer**: +10 points
- **Level Up**: Every 50 points (5 correct answers)
- **Lives**: Start with 3 lives (❤️❤️❤️)
- **Game Over**: When all lives are lost

#### Difficulty Levels
- **Easy (Levels 1-3)**: Basic molecules like Water, Oxygen, Ammonia
- **Medium (Levels 4-7)**: Intermediate molecules like Glucose, Ethanol, Methane
- **Hard (Levels 8+)**: Complex molecules like Caffeine, Aspirin, Benzene

The difficulty increases smoothly as you progress, introducing more challenging questions gradually.

The game includes 15 different molecules across three difficulty levels:

### Easy Level
- Water (H₂O)

- Sodium Chloride (NaCl)

### Medium Level

- Caffeine (C₈H₁₀N₄O₂)
- Aspirin (C₉H₈O₄)
- DNA Base - Adenine (C₅H₅N₅)
- Benzene (C₆H₆)

## Tips for Success

1. **Read Carefully**: Take time to read both the molecule name and the question
2. **Use the Tutorial**: Review the tutorial if you're unsure about game mechanics
3. **Learn from Mistakes**: Incorrect answers show the correct answer briefly - use this to learn
4. **Adjust Settings**: Configure sound and visual feedback to your preference
5. **Take Breaks**: Use the pause feature to take breaks and stay focused
6. **Practice**: The more you play, the more chemistry knowledge you'll gain!
